# Pass by Value in C

This program demonstrates pass by value, where a copy of the variable
is passed to the function. Changes made inside the function do not
change the original variable.

## File

pass_by_value.c

## Concepts Used

- Function arguments
- Function parameters
- Pass by value
- Function call

## How to Run

gcc pass_by_value.c -o pass_by_value
./pass_by_value

## Sample Output

Before function call: 50
Inside function: 100
After function call: 50
